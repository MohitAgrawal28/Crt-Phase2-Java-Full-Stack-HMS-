## Charge Calculations

### Insider Patients (Bed-based)
- Daily Rate: ₹1500 - ₹2000
- Formula: Rate × Number of Days
- Example: ₹1500 × 5 days = **₹7,500**

### Visitor Patients (Consultation-based)
- Consultation Fee: ₹500 - ₹700
- Formula: Fee × Number of Consultations
- Example: ₹500 × 3 = **₹1,500**

## Common Tasks

### View All Patients
Methods available in code:
```java
system.displayAllPatients();
```

### View All Doctors
```java
system.displayAllDoctors();
```

### View All Appointments
```java
system.showAppointments();
```

### Check Bed Status
```java
system.displayAvailableBeds();
```

### Add New Patient
```java
Patient newPatient = new Insider("P999", "John Doe", 1500);
system.addPatient(newPatient);
```

### Add New Doctor
```java
Doctor newDoctor = new Doctor("D999", "Dr. Smith", "Cardiology");
system.addDoctor(newDoctor);
```

### Schedule Appointment
```java
system.scheduleAppointment("P001", "D001", "2026-07-01");
```

## Troubleshooting

| Error | Solution |
|-------|----------|
| "cannot find symbol" during compilation | Use correct Patient/Doctor class names |
| "Driver not found" (MySQL version) | Download mysql-connector-java-8.0.33.jar |
| "Connection refused" (MySQL version) | Start MySQL Server |
| "Duplicate entry" (MySQL version) | Clear data and restart, or use different IDs |
| "Patient/Doctor ID not found" | Ensure patient/doctor exists before scheduling |
